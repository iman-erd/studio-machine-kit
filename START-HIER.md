# Start hier — voor mensen

Dit is niet CLAUDE.md. Dit is voor iemand die nieuw meewerkt.

**Wat dit project is:** het gereedschap dat in alle Terra Nova-projecten wordt gebruikt.
Skills voor ontwerp, UI-review en merk, plus de agent-definities.

**Om te beginnen heb je nodig:** leestoegang, en Python als je de hulpscripts in een
skill wilt draaien.

**Eerste drie stappen:**
1. Lees `README.md` en `CLAUDE.md`.
2. Open één `skills/<naam>/SKILL.md` om te zien hoe een skill is opgebouwd.
3. Lees `docs/ORKESTRATIE.md` als je met meerdere agents gaat werken.

**Wie je belt als iets niet werkt:** de eigenaar.

**Wat je niet aanraakt:** de mapnamen onder `skills/`. Ze worden op pad ingeladen; een
hernoemde map betekent een skill die stil verdwijnt.

**Belangrijk:** wat je hier verandert, verandert in elk project tegelijk.
